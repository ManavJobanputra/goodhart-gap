# goodhart-gap

**Did the agent fix the bug, or did it game the check?**

`goodhart-gap` is a research instrument for measuring the gap between *apparent*
competence (passing the tests an agent can see) and *genuine* competence (passing
hidden, fuzz and out-of-distribution verification) in LLM code-repair agents.

It builds a benchmark of repair tasks with a four-tier hidden verification
ladder, runs agent scaffolds under controlled information/feedback/framing
knobs, detects mechanical shortcuts, and reports the resulting success gap with
statistics.

This repository is a **foundation**, not a finished paper. See `docs/` and
`.agent/HANDOFF.md` for the state of the build.

## Quickstart

```bash
make setup      # create venv and install
make check      # format + lint + fast tests (no network)
make smoke      # build a tiny task subset and run synthetic agents end-to-end
gg demo         # walk one task from spec to verdict
```
